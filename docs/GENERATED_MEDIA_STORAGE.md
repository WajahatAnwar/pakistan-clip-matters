# Generated media measurement

Run `php artisan operations:measure-generated-storage` to refresh the dashboard's local generated-media snapshot. An hourly entry is registered in `routes/console.php`; automatic execution depends on the existing Laravel scheduler being run by the host.

The command sums actual file lengths for outputs in producer-defined locations: extracted/downloaded audio named `audio_*.mp3` or `audio_*.webm` in `storage/app/temp`, and converted MP4 files in `storage/app/tmp`. Downloaded original video copies and MTS source copies are counted separately and excluded from generated bytes. Other files are classified as unknown; symlinks and directories are excluded. Private backups, uploads, logs, application assets and index storage are outside this scope. The scan is bounded at 10,000 files and performs no deletion or provider calls.

The snapshot is written atomically to `storage/app/private/operations/generated-media-v1.json`, independently of source/index audit data, and survives cache clears. A failed scan retains the prior dated measurement. This is a point-in-time local measurement; it does not claim remote Dropbox/YouTube/object-storage generated-media coverage. Zero bytes after cleanup is a measured result, not missing data. The dashboard displays the measurement time and remote-scope limitation.
